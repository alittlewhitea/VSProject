# DreamFace Creative Studio 重构方案

## 规范与目标

本轮以 `public/DreamFace-DESIGN.md` 为视觉依据：明亮编辑式外壳、真实作品为中心、独立深色预览舞台。保留原有绿色 Logo 和深浅主题开关。初次访问默认浅色，已经保存的外观偏好继续有效。

2026-11-05 预览尺寸复查：视频工作台的默认画布改为随窗口高度收缩，桌面最高 420px；手机约 200–280px。案例缩略图改为 112×63px（手机 96×54px），减少案例条与重复元信息的高度。媒体继续完整包含显示，保留原文件和全屏入口，仅作用于视频工作台样式。

该次调整的生产构建和输入检查通过，浏览器验证六档尺寸无横向溢出，桌面案例条可在首屏显示；案例选择及原有时长行为保持，全屏验证为 1440×900。报告与截图位于 `outputs/studio-compact-preview-20261105/`，客户端异常及付费请求均为 0。

参考原则来自规范链接的 [ElevenLabs](https://styles.refero.design/style/031056ff-7af1-46db-8daa-115f731c5d26)、[Figma](https://styles.refero.design/style/5fd3b3b4-02ab-456a-87aa-e4395636b671)、[Raycast](https://styles.refero.design/style/3b6a17f0-3bdf-418c-a95e-0b89e5a8b2f8)。仅参考排版、内容层级和预览区原则，实际 Tokens 使用项目设计规范，不复制第三方字体、素材或专有界面。

## 现状分析

| 组件 | 职责与现状 | 本轮调整 |
|---|---|---|
| `studio-client.tsx` | 统一维护登录、模型、参数、报价、上传、任务、支付、URL 状态 | 仅调整页面组合和工作流切换组件的位置 |
| `studio-home.tsx` | 本地创意草稿、三种入口、现有案例、真实任务列表 | 紧凑编辑式介绍区、作品卡、可复用的创建面板 |
| `studio-header.tsx` / `studio-navigation.tsx` | 积分、购买、语言、账户、菜单、导航 | 统一安静的浅色外壳与层级，保留全部操作 |
| `workflow-switcher.tsx` | 切换工作流，调用现有回调 | 使用统一分段控件；视频切换放入左侧 Inspector |
| `video-settings.tsx` | 提示词、增强、首尾帧、模型、参数、高级项、生成、样例和最近视频 | 保留回调与真实报价；拆分 Inspector 与深色 Stage 的视觉职责 |
| `model-picker.tsx` | 真实模型列表、报价、筛选、焦点与键盘交互 | 提供紧凑卡片外观，保留信息和选择能力 |
| `studio-theme.css` | 已有主题变量与首页样式 | 建立规范中的 `--df-*` Tokens，以别名兼容其他工作台 |

## 实施顺序

1. 定义颜色、字体、间距、圆角、阴影、动效 Tokens；加入按钮、链接、面板、分段切换和分区标题组件。
2. 统一侧栏与顶部栏，默认浅色外壳；保留深色模式和所有登录／语言／积分入口。
3. 重构创作首页。所有入口沿用现有 Studio 路由，所有作品来自已有媒体或任务数据。
4. 重构视频工作台。左侧约 38%，右侧约 62%；首尾帧和高级项保持可发现；右侧区分案例、排队、生成、失败、完成及无输出。
5. 使用现有项目检查、生产构建、浏览器交互与截图验证，检查桌面、短窗口、手机、16 语言与 RTL。

## 行为边界

- 不修改 API、数据库、价格、模型配置、登录、支付、URL 协议和任务同步规则。
- 不硬编码积分、不模拟用户作品、不加入没有回调的按钮。
- 保留样例选中／点击／播放带入匹配提示词的既有行为，保留 Ctrl／Command + Enter、高级参数和首尾帧规则。
- Stage 只消费已有任务数据；不会为了展示而请求新的模型或生成素材。
- 避免把带有明显转播水印的素材作为首页精选；未确认来源的现有条目不作为新视觉的主视觉。保持现有图库与案例访问能力。
