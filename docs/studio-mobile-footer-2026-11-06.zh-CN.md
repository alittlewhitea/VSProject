# 移动端工作台底部排版修复

## 问题与调整

- 旧版六项底部导航被移入外层网格第二行后，在内容较短的增强修复、移除背景和音频页面被拉伸，出现大块导航和高亮背景。现代工作台移动端隐藏这组重复导航，沿用已有的左上角菜单访问首页、工作区和项目；保留购买积分入口。
- 音频底部改为两列参数布局：模型占整行，语音的声音和语言并排，音乐的格式与更多设置并排；生成按钮占整行。
- 图片工具的输出格式控件统一为整行宽度，积分说明分行排列，避免窄屏文字挤成一行。
- 仅调整 CSS 和一个用于样式选择的 `data-utility-workflow` 属性；原有事件、状态、API、参数与计费保持不变。桌面端不应用本次手机布局规则。

- 320、360、390、430px，增强修复、移除背景、文字转语音、音乐生成，共 16 个场景通过。

- 上传图片、声音/语言/格式选择、高级设置开合、左上角菜单与生成请求参数正常；生成请求全部拦截，未实际扣费。
