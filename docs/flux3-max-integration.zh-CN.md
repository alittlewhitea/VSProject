# FLUX 3 Max 视频接入

- 文生视频：`blackforestlabs/flux-3-max/text-to-video`。
- 图生视频：`blackforestlabs/flux-3-max/image-to-video`；支持首帧和可选尾帧。
- 两个工作流共用 `flux-3-max-video` 标识，使用现有 FAL_KEY、队列、任务和积分流水，无需新增数据库表。
- 支持 5–20 秒、720p／1080p、原生音频、low／high 推理强度和 seed。默认 5 秒、720p，音频开启，推理 high。
- API 文档中的优惠单价已经是 75% OFF：720p 为 $0.0425/秒、1080p 为 $0.0725/秒；不再重复打折。
- 积分沿用常规换算：美元成本 × 150 × 1.65，按整段视频计算后向上取整。文生、图生同价，关闭音频不改变单价。
- 优惠期内 5 秒：720p 53 积分、1080p 90 积分；原价分别为 211、359 积分。
- 经站点所有者确认，优惠包含11月7日全天：北京时间 2026-11-08 00:00 截止。到期后单价恢复 $0.17/秒、$0.29/秒，并移除 75% OFF 标签。
- 期限由 `src/lib/flux3-max.ts` 统一定义。浏览器自动刷新报价；服务端最终计费。过期的浏览器报价会返回409，要求用户确认更新后的积分后重新提交，不按更高价格直接扣款。
- 已创建任务的积分不随优惠到期而改写，失败退款仍沿用已有记录。

验证：`npm run verify:flux3` 测试真实服务端路由的模拟执行；`npm run check` 包含接口、边界时刻、积分、语言和构建检查。`scripts/verify-flux3-max-ui.mjs` 为可选浏览器模拟检查，所有 API 请求使用测试数据，不进行真实生成或数据库写入。
