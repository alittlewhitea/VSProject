# Avatar 工作台 HTML 视觉整合

依据用户提供的 `gemini-code-1793949369665.html`，仅为 Avatar 输入工作台及其模型弹窗添加视觉层。该次明确指定的渐变、发光和微动效覆盖旧规范中对应的视觉限制，其他工作台继续沿用已有设计。

- 主卡片保持 896px 最大宽度，加入细渐变描边、轻阴影、紫色标记、等宽字数信息 Badge、64px 上传卡片和渐变分割线。
- 上传卡片悬浮上移、加号旋转；模型和参数按钮使用图标、细边框与轻微抬升。生成按钮使用紫色渐变、Shimmer 扫光、按压反馈及毛玻璃积分 Badge，禁用时不播放扫光。
- 复用现有 ModelPicker 弹窗、搜索、分组、选择处理函数、Escape、遮罩关闭、焦点约束与关闭后焦点恢复。Avatar 弹窗使用 576px 卡片、模糊遮罩、进入动效、选中状态及右侧价格；其他工作区弹窗样式不变。
- 模型、积分、价格、字数、时长和分辨率仍由现有状态与价格计算提供。没有复制示例 HTML 的静态模型清单、静态价格或 250 字上限，没有导入其 DOM 事件脚本或 CDN Tailwind 运行时。
- 深浅主题、移动端竖屏/横屏及 RTL 使用同一视觉层；减少动态效果设置关闭动画和扫光，移动端生成按钮仍占整行。已有上传、选人、创建人物图指南、语音设置、Avatar 库、收藏和所有有效参数保留。
- 后续收尾：弹窗左上角使用参考 HTML 中的双星 SVG 图标；删除工作台标题右侧“全部项目”链接。人物库分类收敛为全部、收藏，筛选只保留性别，详见 Avatar 筛选说明。
- 用户后续确认将该视觉扩展到视频、图片及音频工作台；共用已有视觉层和模型选择处理函数，详见 `studio-premium-workspaces-2026-11-06.zh-CN.md`。本节最初的“仅 Avatar”范围指第一阶段。

## 不变性与验证

- 修改前记录全部 API 路由及工作台状态、价格与 Avatar 业务模块的内容摘要，修改后核对 54 个文件完全一致。
- 通过 TypeScript AST 对照 AvatarComposerInput、AvatarSettings、ModelPicker 中原有 `on*` 事件、`value`、`checked` 和 `disabled` 属性，所有表达式和出现次数保持一致。
- `npm run check`、生产构建及浏览器验证通过。浏览器覆盖 1600px 英文、1280px 中文、390px 中文、320px 阿拉伯文、844×390 横屏，验证渐变、扫光、毛玻璃、模型搜索与选择、实际参数提交、原输入保留、主题及减少动态效果。
- 生成请求均被隔离测试拦截，无付费生成。截图及验证报告位于 `outputs/avatar-premium-20261106/`，另提供真实公共 Avatar 素材的只读本地预览截图。
