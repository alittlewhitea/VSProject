# 首页示例、上传入口与工作台设置修订

按用户本轮要求恢复既有内容并调整前端，不修改生成、积分或支付 API。

- 首页恢复既有棒球转播、CGI 分层、东京街头赛车、观众冲入球场四个视频及原始链接。取消首页的独占播放分组，可见示例分别播放；离开视口、隐藏标签页和卸载时仍暂停。其他独占播放场景保留原组件能力。
- 首页改为带“＋”及上传名称的文件选择按钮，支持 JPEG／PNG／WebP、30MB 上限、缩略图、移除与读取错误提示。
- 已上传图片时，选择视频进入图生视频，选择图片进入图生图；开始创作按钮遵循相同规则。选择音频忽略图片，正常进入音频工作台。图片通过现有客户端参考图状态传递，不写入 URL，也不提前提交生成请求。
- 用共享原生选择组件调整视频时长、宽高比、分辨率和图片参数：清晰标签、44px 控件、统一边框和箭头、深浅主题及原生键盘操作，保留原选项和值变更回调。
- 图生图编辑区取消内部限高，由页面自然滚动，保留参考图、模型选择、参数、高级设置和生成按钮。参考图 URL 输入区单独设置合理高度。
- 视频编辑区改用普通容器承担滚动，内部 fieldset 继续负责提交时禁用控件，避免 fieldset 的原生布局与底部操作区发生遮挡。
- 删除增强修复的 Topaz／Standard V2／2x／主体／人脸80%／输出说明卡，以及背景移除无需提示词的说明卡。单一固定模型不再重复显示模型介绍，实际上传、输出格式选择与生成行为保留。
