# HeyGen 参考视频与生成同款

## 使用方式

视频工作台新增“参考视频”标签，对应 `/studio?mode=video&workflow=reference-to-video`。填写一条公开可访问的视频直链，输入提示词；需要使用自己的产品或人物时，可上传主体图片。初版界面支持一条视频链接及最多四张 JPG、PNG、WebP 图片，每张不超过 30MB；这是本项目的输入限制，不代表供应商的最大配额。

首页混合模板瀑布流与视频工作区的 Motion、UGC、TikTok 视频预览，右下角统一使用“去制作同款”。点击带入该条模板的完整视频直链、模板 ID 和当前语言的默认提示词，进入参考视频工作区；不会自动生成或扣积分。已有主体图片和用户改过的提示词在同一工作区切换模板时保留。

主体图片可选，可单独删除、追加、重新选择或拖入。参考视频预览默认折叠，展开后才加载，关闭时卸载播放器。长视频链接保持可编辑，包含查询参数的链接完整传递。

默认输出为 5 秒、768p、自动匹配宽高比，保留安全检查开关与随机种子。该模式使用 HeyGen 自带的 `prompt_enhancement: turbo`，原有文生视频与图生视频的 AI 提示词增强保持原流程。

## 共用默认提示词

Motion、UGC、TikTok 及首页的视频“去制作同款”共用 `studio.referenceVideo.templatePrompt`，参考视频工作区的“给我灵感”也读取同一条文案。2026-11-05 更新为同一套语义的 16 语言译文，不根据具体商品写死动作或分镜。

新版明确 `<Video 1>` 提供场景、分镜、运镜、剪辑节奏、光影和构图；有图时，`<Picture 1>` 提供主要主体，其他图片辅助。保留主体身份、造型、比例、材质、颜色与已有标识，替换视频中的对应主体，不重复追加，不沿用主体图背景或静态构图。动作与互动应适配新主体并保持物理合理、跨镜头一致。根据输出时长保留原片有意义的切镜或连续镜头结构；没有图片时仍允许参考视频生成变体。不强制所有模板多镜头、倒水或结尾停留。

此次仅更新默认提示词及说明，接口字段、提示词增强设置、模型、价格和其他生成流程保持原样。新点击模板或点击“给我灵感”会加载新版，已打开 URL 中的旧提示词及用户改过的内容不会被强制覆盖。实际生成质量不能由文案更新保证，本次未额外调用付费生成。

## 接口与计费

调用现有服务端生成入口，转发到 `heygen/heygen-video/reference-to-video`：

- 视频链接放入 `reference_video_urls`。
- 上传的主体图片放入 `reference_image_urls`。
- 两类输入均保存在现有任务设置 JSON 内，沿用 fal 队列、状态轮询、输出解析、失败退款及幂等处理；不需要数据库迁移。
- 只允许视频工作区的 HeyGen 使用此工作流；校验链接协议、输入类型、数量、时长、分辨率与宽高比。非法输入或报价过期在扣积分前拒绝。未配置供应商时拒绝创建模拟任务。
- 沿用现有 HeyGen 价格与基础档成本／高清档成本 ×1.2 的积分规则。10 月 31 日活动已结束，2026-11-05 默认 5 秒、768p 预计 18 积分；生成前展示实际报价。

官方说明支持图片和视频共同参考，但定位是重新生成一段新视频，没有保证逐帧精准替换主体、完全保留原片。默认提示词要求参考运镜、节奏、光影、构图，提供图片时采用其中的主体并保留身份、形状与品牌特征，不复制无关标识或文字。[官方 API 文档](https://fal.ai/models/heygen/heygen-video/reference-to-video/api)

## 登录与回归检查

为新工作区保存参考视频、上传主体、提示词和设置到原有登录草稿，登录后返回当前工作区。只在用户明确点击“登录后生成”的流程中继续其生成请求；仅点击模板不会发起生成。其他工作区的登录入口保持原行为。

16 种语言覆盖新标签、说明、错误提示和默认提示词，保留深浅外观与 RTL。检查包括：

- 真实服务端处理器的 URL-only 与视频＋主体图片请求、确切端点与字段、种子、安全开关、任务设置、常规积分和过期报价。
- 非法输入在扣积分前拒绝；未配置供应商时不生成、不扣积分。
- 1440px 英文和 390px 中文下的 URL 编辑、多图上传与删除、三个视频分类的生成同款、首页混合模板入口、标签切换。
- 音频 → 视频 → 参考视频切换，16 语言在 320px 下的横向溢出，图片模板原入口及双图请求回归。
- 未登录上传主体后点击登录，草稿保存与登录后恢复的实际浏览器请求检查。
- 仓库的类型、语言、安全、支付、模型、任务历史、输入、导航、模板虚拟列表检查与生产构建。

浏览器报告：`outputs/studio-reference-video-20261105/regression.json`；图片回归：`outputs/studio-template-two-images-20261105/regression.json`。生成请求均使用本地拦截或隔离的处理器测试，没有真实付费生成，实际主体替换质量仍需使用素材实测。

本轮未推送或部署。本地生产预览使用 3012 端口。
