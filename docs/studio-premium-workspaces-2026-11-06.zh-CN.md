# 视频、图片、音频工作台统一高级视觉

按已确认的 Avatar 工作台视觉，扩展共享卡片和模型弹窗样式；此次仅修改前端展示。

- 主输入卡片统一为最大 896px、细渐变边框、轻阴影、紫色标记和字数 Badge。模板与 Gallery 保留原来的宽度和数据。
- 常用参数增加时长、比例、清晰度、音色、语言、文件格式图标；仍使用原生 select 和原有取值、事件。低频设置保留折叠入口。
- 生成按钮统一使用紫色渐变、Shimmer 扫光、毛玻璃积分 Badge、悬浮和按压反馈；禁用和减少动态效果时不播放扫光。
- 复用同一套模型弹窗：双星图标、搜索、分组卡片、真实模型和报价、选中标记、进入动画、Escape 与焦点恢复。没有创建虚构模型或复制示例价格。音频当前只有一个提供商时继续保持原有限制。
- 视频首尾帧、参考视频链接、模板定位、图片参考与增强处理、GPT 2.6 参数、音色、语言、时间戳、歌词及音乐编码选项全部保留。
- 保留深浅主题、移动端全宽生成按钮、RTL、原页面滚动及模板列表。清理旧 sticky 定位遗留的 inset，防止桌面工具栏偏出卡片。
