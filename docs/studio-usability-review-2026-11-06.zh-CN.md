# 工作台使用体验复查（2026-11-06）

本次基于视频、图片、音频和 Avatar 的新设计，检查用户操作流程及异常恢复。只修改前端，保留现有生成 API、后端任务与计费实现。

## 已复现并修复

1. **增强修复、移除背景无法再次选择同一图片。** 清除预览后，文件控件仍保留上次选择，浏览器不会再次触发 change。读取文件后重置原生控件值，沿用原上传回调。
2. **图片工具上传入口无法通过键盘使用。** 将隐藏上传控件改为可聚焦的视觉隐藏控件，为图片工具和视频首尾帧上传补上可见焦点与名称。Tab 可定位，Enter 可打开系统文件选择器。
3. **误拖非图片文件导致素材丢失。** Avatar、增强修复、移除背景在处理非图片文件时可能清除原图；图生图则无错误反馈。现在前端先检查文件类型，错误时沿用已有本地化错误提示，保留原图，不调用原上传回调。
4. **未登录点击生成丢失草稿或回错工作区。** 视频、音频和 Avatar 之前直接跳转通用登录入口，未保存草稿。现在与 GPT 图片和参考视频一样，调用已有 saveLoginDraft，并将当前工作区放入登录返回地址。保存失败时保留当前页面并显示已有错误提示。

## 验证范围

- 桌面和手机端 27 个工作流场景：原始生成参数、模型与分辨率、引用图片、参考视频、GPT 高级参数、音频与歌词。
- 500、429、非 JSON 网关错误、网络中断后恢复；保留输入，允许重试。
- 连续点击与快捷键重复操作只发送一次生成请求。
- 空输入拦截、积分不足购买弹窗、模型搜索无结果、键盘焦点、Escape 关闭与恢复页面滚动。
- 手机端菜单、工作区切换、深浅模式、语言和购买积分弹窗。
- 清除后重选同一文件、键盘选择文件、非法文件保留原图。
- 登录前草稿保存、返回原工作区及登录后恢复并继续原请求。

浏览器检查采用独立会话和被拦截的生成请求；不进行真实扣费、支付或生产数据库写入。不能据此保证第三方模型服务始终可用。
