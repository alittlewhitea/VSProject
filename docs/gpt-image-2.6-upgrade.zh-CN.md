# GPT Image 2.6 升级说明（2026-11-06）

本次将 GPT 文生图、图生图整体升级至 2.6，模型列表不再提供 2.5。Flare 沿用 `chatgpt-image` 标识，Sunburst 使用 `gpt-image-2.6-sunburst`。旧书签、浏览器偏好、登录草稿中的旧 Sunburst 标识会自动映射至新模型；不再发起任何 2.5 生成请求。历史任务记录与结果不改写。

## 接口与默认设置

四条 fal 接口：

- `openai/gpt-image-2.6/flare/text-to-image`
- `openai/gpt-image-2.6/flare/edit`
- `openai/gpt-image-2.6/sunburst/text-to-image`
- `openai/gpt-image-2.6/sunburst/edit`

保留当前工作台、登录与积分扣费、队列轮询、失败退款、项目历史流程。默认质量 Low、推理 Low、PNG、自动背景、单张输出，避免直接采用供应商 High 默认档导致默认消耗上涨。Flare、Sunburst 各自原有默认画布保留。GPT 的安全检查默认开启，可在新增设置中切换；其他模型的安全设置不受影响。

不开放 `sync_mode=true`，因为该模式返回 data URI，且供应商历史不可用，会破坏项目现有异步任务与历史结果链路。

## 新增设置

- 六档质量：Auto / Low / Medium / High / XHigh / Max。
- 独立推理强度：Low / Medium / High。
- 背景：自动、透明、不透明；JPEG 不显示透明选项。
- 原有画布 + 2K、4K、自动尺寸、自定义宽高。
- 自定义尺寸：16 的倍数、最大边 3840 px、最大比例 3:1、总像素 655,360–8,294,400。
- 批量 1–10 张，结果可逐张预览；项目中选中的图片用于下载与再次引用。
- PNG / JPEG / WebP / GIF；文生图另外支持 SVG，图生图不显示 SVG。
- JPEG / WebP 压缩 0–100，0 会正常传递。
- GIF 帧数 2–16，帧时长 20–2000 ms，并按 10 ms 对齐。
- SVG 转换模型：gpt-6-astra、gpt-5.5、gpt-5.4、gpt-5.6-terra、gpt-6-luna；SVG 限单张输出。
- 图生图最多 16 张参考图，可选择编辑遮罩或标注 PNG，二者互斥；支持 URL 或本地上传。
- 标注 PNG 需要仅包含透明底标注，并与第一张参考图尺寸一致。本地上传会检查 PNG 类型与尺寸；公网 URL 的实际内容由供应商进一步校验。
- 提示词上限 32,000 字符；无效组合前后端拦截。

GIF 的所有帧和输出共用供应商请求像素预算。文档没有公开该预算的确切数值，因此没有捏造一个本地硬上限；界面提示在供应商拒绝时减少尺寸、帧数或张数。

设置、提示与错误文本已覆盖项目现有 16 种语言。折叠高级设置保留值，切换 Flare/Sunburst 保留用户提示词、参考图和兼容设置。登录草稿包含新增字段。切换参考主体或成功生成后清理旧编辑遮罩/标注，避免错用上一张图的指导文件；异步读取指导图时也防止覆盖用户后来修改的参数。

## 积分与成本口径

2026-11-06 已由 [GPT 2.6 盈利定价说明](gpt-image-2.6-pricing-2026-11-06.zh-CN.md) 替代升级初版的成本预算。两款 GPT 2.6 按官方输出 token 公式估算，加入输入、推理和格式预算，以最便宜积分包单价反推 20% 收入利润率目标，另预留收入的 5% 作为支付手续费预算。不再叠加高清 ×1.2。

默认 1024×768 / Low / 单张、短提示词约为 6 积分；参考图、尺寸、质量、张数、GIF 与 SVG 会改变报价。积分包售价、其他模型规则保持原样。生成按钮、模型选择和服务端共用估算逻辑；旧报价在扣费前返回 409。

报价仍为估算，实际供应商用量与支付手续费需要真实账单校准。
