# GPT Image 2.6 盈利定价说明（2026-11-06）

## 范围与目标

适用于 Flare（`chatgpt-image`）与 Sunburst（`gpt-image-2.6-sunburst`）的文生图、图生图。两者目前公开的 token 单价相同，使用同一计价规则；具体输出与实际用量可能不同。

用户要求约 20% 盈利。本次采用**销售收入利润率目标 20%**，另外预留收入的 5% 支付手续费预算。5% 是应用预算假设，不是已经核实的 PayPal 或其他支付服务商收费标准；未计入税费、服务器、人工等费用，不能视为最终净利润保证。

积分包售价和数量不变。定价读取与结账相同的纯数据目录 `src/lib/credit-pack-prices.ts`，当前最低收入单价为 Pro Pack：$49.99 / 11,000 积分，约 $0.00454455/积分。其他模型沿用原有规则。

```text
单张积分 = ceil(单张估算供应商成本 / ((1 - 20% - 5%) × 最低付费积分单价))
批量积分 = 单张积分 × 张数
```

积分向上取整、购买单价更高的积分包，都会提高相对估算成本的利润率。不再额外叠加高清 ×1.2。免费赠送或优惠券折价积分不具有上述收入单价，需要另行考虑获客预算。

## 成本估算依据

采用 [OpenAI 图片生成指南的输出 token 计算器](https://developers.openai.com/api/docs/guides/image-generation#calculating-costs)，替换升级初版未校准的 Low/Medium/High 固定预算。参考 [fal Flare 定价](https://fal.ai/models/openai/gpt-image-2.6/flare/text-to-image) 与 [Sunburst 定价](https://fal.ai/models/openai/gpt-image-2.6/sunburst/text-to-image)：文本输入 $5/M，文本输出 $10/M，图片输入 $8/M，图片输出 $30/M；不预先假设缓存优惠。

光栅单张输出 token 计算：

1. 质量 Low / Medium / High / XHigh / Max 对应长边网格 16 / 24 / 48 / 64 / 96。
2. 短边网格 = 长边网格 × 短边像素 / 长边像素，遇到精确 .5 时向偶数取整。
3. 基础 token = ceil(长边网格 × 短边网格 × (2,000,000 + 实际像素面积) / 4,000,000)。
4. Low / Medium 乘 4.2 / 3.3 后四舍五入，其余保持；按 $30/M 换算。

例如 1024×1024 / Low 输出 823 token，仅图片输出成本 $0.02469；不能再按旧预算 $0.006 计费。

以下仍是**应用估算预算**，需要真实账单校准，不是供应商固定费用或严格用量上限：

- 提示词以去除首尾空白后的 UTF-8 字节数作为未缓存 token 预算，至少预留 32 token；不使用旧的字节数 / 3 估计。
- 推理 Low / Medium / High 暂预留 128 / 1,024 / 4,096 个文本输出 token。
- 每张参考图暂预留 1,500 图片输入 token（$0.012），遮罩或标注图额外计一张。复杂参考图可能超出该预算。
- Auto 质量按 Max 预算；Auto 尺寸按最大合法正方形 2880×2880 预算。宽屏 4K 在同质量下不一定是最贵尺寸。
- GIF 暂按逐帧扩大光栅输出预算；实际共享像素预算与 token 用量可能不同。
- SVG 加入所选转换模型预算：提示词加 4,096 输入 token、8,192 输出 token。每百万输入/输出预算单价：GPT-6 Astra $10/$50、GPT-5.5 $5/$30、GPT-5.4 $2.5/$15、GPT-5.6 Terra $2/$12、GPT-6 Luna $0.1/$0.5。参考各 [官方模型页面](https://developers.openai.com/api/docs/models/gpt-6-astra)，不宣称是已核实的 fal SVG 最终账单。
- 单张总成本向上对齐 $0.0001，再换算积分。逐张估算使批量价格可预测，可能高于供应商按整批取整的成本。

## 常见价格示例

两款模型同设置价格一致。以下为短提示词、Low 推理、PNG、单张；长提示词、参考图和其他设置会改变报价。

| 设置 | 估算成本 | 积分 |
| --- | ---: | ---: |
| 1024×768，Low | $0.0184 | 6 |
| 1024×768，Medium | $0.0313 | 10 |
| 1024×768，High | $0.0376 | 12 |
| 1024×768，XHigh | $0.0657 | 20 |
| 1024×768，Max | $0.1459 | 43 |
| 1024×1024，Low | $0.0262 | 8 |
| 1024×768，Low，1 张参考图 | $0.0304 | 9 |

默认 6 积分按 Pro Pack 单价对应收入约 $0.02727，减去估算成本和 5% 手续费预算后约 27.5% 收入利润率；这是整数积分向上取整的结果。

## 报价、扣费与退款

- 模型选择、生成按钮、积分包示例、服务端均读取同一估算器。
- 客户端提交 `expectedCredits`，服务端重新计算；不一致返回 `409 generation_price_changed`，在扣费、供应商调用前拦截。旧页面 1 积分请求也会被拦截。
- 未带客户端报价的请求仍由服务端按新价格计费，不信任客户端自报积分。
- 已完成任务不追扣。失败且有供应商实际费用时，GPT 按成本与 5% 手续费预算折算保留积分，不加 20% 利润；保留额始终不超过原扣费，剩余退回。未报告费用或费用为零时退回全部原扣费。
- 生成提交、状态查询、用户任务列表、后台任务同步、定时同步五条失败处理入口均传递模型标识，避免 GPT 部分退款继续使用旧的 150 积分/美元换算。
