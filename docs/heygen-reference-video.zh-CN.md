# HeyGen 参考生视频接口对齐

核对日期：2026-11-16。来源为用户提供的接口说明以及 fal 当前 OpenAPI：

- [API 文档](https://fal.ai/models/heygen/heygen-video/reference-to-video/api)
- [OpenAPI Schema](https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=heygen/heygen-video/reference-to-video)

简化文档没有列出素材数量限制；OpenAPI 的 `HeygenVideoReferenceToVideoInput` 明确声明了 `maxItems`。

| 输入 | 接口要求 | 项目行为 |
| --- | --- | --- |
| 提示词 | 必填，1–32,000 字符 | 必填，提交前校验长度 |
| 参考图片 | 选填，最多 9 张 | 支持 JPEG/PNG/WebP 上传和已有公开图片链接 |
| 参考视频 | 选填，最多 3 个 | 每行一个公开 HTTP(S) 链接，按需预览 |
| 参考音频 | 选填，最多 3 个 | 每行一个公开 HTTP(S) 链接 |
| 时长 | 5–15 秒，默认 5 秒 | 保留显式时长选择 |
| 分辨率 | 480p、768p、1080p、2k；接口默认 768p | 平台保留 480p 默认值，前后端统一 |
| 随机种子 | 0–4,294,967,295 的整数，选填 | 留空随机；前后端校验范围 |
| 提示词增强 | turbo / quality / ultraquality / disabled | 更多设置可选，默认 turbo；精确对白强制关闭改写 |
| 安全检查 | 默认 true | 默认开启，保留显式设置 |

视频不再是强制输入。仅提示词、仅图片加提示词、仅音频加提示词，以及混合素材均可提交；空素材数组不发送空链接。参考音频和实际提示词增强模式会保存在任务设置中，登录草稿也保留这些选项。

平台上传预算为单张 30 MB、上传图片合计 40 MB，独立于供应商的素材数量限制。这保证九图组合不会因 Base64 请求体超出平台限制而在提交后失败；总量包含已上传的图片。远程图片大小由供应商校验，平台不下载远程媒体。

1080p/2K 的 16:9、9:16 限制沿用现有保护。素材为空时，“灵感”提示词不再引用不存在的视频。

2026-10-31 的半价促销已经结束。项目已有日期判断，当前按常规供应商成本：480p/768p 为 $0.02/秒，1080p/2K 为 $0.06/秒；本次未改动积分计费方式或赠送积分规则。

现行积分比例存在成本风险：5 秒 480p 的供应商成本约 $0.10，收费 15 积分；按最低付费单价 $49.99/11,000 积分计算，收入约 $0.068。本次保留现有积分定价。
