# 上传图片与视频示例行为

- 修复图生图切换到 Nano Banana 时清空已上传文件的问题。GPT Image、Sunburst、Nano Banana 2.1、Pro、Lite 之间切换保留用户文件和用户 URL。
- 用户上传图片时清理系统默认示例 URL，避免将默认参考图和用户图片一起传给模型；其他用户参考 URL 继续保留。
- 图生视频切换模型保留首帧。切到不支持尾帧的模型，只移除尾帧并沿用原提示；首帧不需要重新上传。
- URL 的 prompt/reference 只在首次进入、模式改变或参数值真的变化时应用；仅改变 provider 不再用 URL 中的旧图或旧文案覆盖用户上传/编辑。
- MiniMax H3 Max 与 H3 Max Turbo 在文生视频、图生视频中默认提示词为空，用户输入的自定义文案继续保留。Avatar 默认台词保持原有行为。
- 右侧大视频的点击/播放、缩略图及切换示例操作带入对应视频的提示词。初次渲染和选择模型不会自动带入。示例选择保留当前模型、上传图片及清晰度，并仅在当前模型支持示例时长时应用该时长。

`npm run verify:studio-inputs` 提取并执行实际上传处理函数、模型切换函数、URL 同步 effect 和预览组件，覆盖上传后连续切换所有支持的模型、尾帧兼容、默认空提示词、自定义文案保留、旧 URL 不回写、显式示例选择。已纳入 `npm run check`，使用隔离 FileReader/React 事件模拟，不访问数据库或付费生成接口。
