# DreamFace IO 临时下架

由于供应商排队问题，暂时停止新任务。文生视频、图生视频、Avatar 的模型列表和当前价格列表已移除 DreamFace IO；文生图、图生图原本不包含此模型。

旧链接或旧浏览器保存的模型选择会回退到该工作流推荐模型。后端在计费、上传文件和提交供应商请求之前拒绝新 DreamFace IO 请求（HTTP 503）。模型可用性在生产和开发环境均返回关闭，数据库开关和环境变量不能覆盖本次暂停；管理页开关暂不可操作。

保留历史模型信息、已有任务状态同步、退款和记录查询。无需数据库迁移，也不删除历史任务或用户文件。

恢复时需确认供应商已恢复，再修改 `src/lib/model-release.ts` 的暂停状态，恢复视频与 Avatar 的模型列表及 `MODEL_PRICING_ROWS` 中的价格行，并调整下架回归测试。不应仅在后台打开开关。

验证命令：`npm run verify:model-suspension`，已包含在 `npm run check` 中。测试不访问生产数据库或付费生成接口。
