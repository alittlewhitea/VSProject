# Seedance 2.5 Flash / Seedream 5.5 接入

新增两个工作台模型，按工作流调用用户提供的五个 fal 接口：

| 工作台模型 | 工作流 | fal 模型 ID |
| --- | --- | --- |
| Seedance 2.5 Flash | 文生视频 | `bytedance/seedance-2.5/flash/text-to-video` |
| Seedance 2.5 Flash | 图生视频 | `bytedance/seedance-2.5/flash/image-to-video` |
| Seedance 2.5 Flash | 参考生视频 | `bytedance/seedance-2.5/flash/reference-to-video` |
| Seedream 5.5 | 文生图 | `bytedance/seedream/v5.5/text-to-image` |
| Seedream 5.5 | 图像编辑 | `bytedance/seedream/v5.5/edit` |

复用现有 `FAL_KEY`、任务预扣积分、持久化提交、队列轮询、webhook 和失败结算流程，无需数据库迁移。模型默认选择和旧模型保持原有设置。集成日期：2026-11-16。

文章 `/video/seedance-2-5-flash` 与模型已双向关联：参考生视频工作台选中 Flash 时显示英文介绍链接（新标签页打开）；文章提供文生视频、图生视频、参考生视频入口，并预选 Flash、720p 和 5 秒。文章的示例提示词按钮会预填对应描述与 10 秒时长。文章价格示例和 FAQ 直接读取项目共用计费函数；页面更新时间、结构化数据及 sitemap 日期同步为 2026-11-16。

## 视频

- 4–30 秒或自动，480p / 720p，原生音频开关、码率和 H.264/H.265 编码。
- 图生视频支持首帧与可选尾帧，比例提交为 `auto`。
- 参考生视频支持最多 10 张图片、5 个视频 URL、5 个音频 URL，以及参考、编辑、延长和自动任务。编辑与延长必须提供视频。参考图支持上传，视频和音频使用公开 HTTP(S) 链接，每行一个。
- 视频字段根据任务显示必填或选填，图片和音频始终选填；各字段说明用途，详细格式与大小限制可展开查看。
- 参考提示词支持 `@` 素材补全、缩略图、键盘选择、引用高亮和悬停预览。删除图片时同步清除对应引用并更新其余编号，避免引用错图；保留原生撤销和中文输入。
- 模型文章入口、计价说明及输入提示仅在参考生视频中显示。
- 视频编辑按接口约定提交自动时长与自动比例；延长使用自动比例。
- 供应商仍会校验素材：视频每个 1.8–30.2 秒 / 最大 200 MB，合计 ≤30.2 秒，每边 300–6000 像素、宽高比 0.4–2.5、24–60 FPS；音频为 MP3/WAV，每个 1.8–30.2 秒 / 最大 15 MB，合计 ≤30.2 秒。当前服务不会下载远程参考视频或音频来预检这些属性。

供应商成本估算取用户文档中的 480p `$0.1442/s`、720p `$0.3094/s`，音频开关不改变费用。有视频参考时，费率乘以 `0.614`，计入输入和输出时长。

自动时长、自动任务或编辑任务统一按最长 **30 秒输出**报价；带参考视频统一按 **30.2 秒输入总时长上限**报价，不接受浏览器提供的时长作为低价依据。该保守报价明确展示在编辑器中，沿用项目的任务预扣积分机制，**不会在成功后按实际时长自动退差价**。如需按实际输入时长精确报价，后续需增加服务端素材校验与不可变存储。

## 图片

- 1K / 1.5K / 2K 自动尺寸，或自定义宽高。
- 自定义总像素 921,600–4,624,220，比例 1:16–16:1；单边最大 14,142 像素。
- 每次 1–6 张输出，最多 10 张参考图；PNG / JPEG，透明背景强制 PNG。
- 文档成本：1K / 1.5K 每张 `$0.03`；2K 每张 `$0.0405`。自定义面积超过 2,610,000 像素使用高档费率。
- 编辑在每张输出的基础成本上，另加每张输入 `$0.012`，即 `(输出单价 + 输入数量 × 0.012) × 输出数量`。

## 积分与利润预算

这五个接口按最低付费积分单价倒推扣分，预留 **20% 收入作为利润空间**、**5% 收入作为支付手续费预算**。不再使用成本乘 150，也不额外叠加 HD 倍率。5% 是预算假设，并非已核实的实际支付费率；实际净利润还取决于供应商账单、支付费用、服务器、赠送积分等支出。

公式：`积分 = 向上取整(估算供应商成本 / (最低付费积分单价 × 0.75))`。最低单价从 `CREDIT_PACK_PRICES` 实时推导；当前最低档为 `$49.99 / 11,000` 积分。

| 内容（不含额外参考素材） | 积分 |
| --- | ---: |
| Seedance 2.5 Flash，480p，5 秒 | 212 |
| Seedance 2.5 Flash，720p，5 秒 | 454 |
| Seedream 5.5，1K / 1.5K，1 张 | 9 |
| Seedream 5.5，2K，1 张 | 12 |

图片逐张向上取整，再乘输出张数；编辑的输入图费用在每张输出计价时一并计算。前端按钮、模型列表、服务端扣费和价格列表使用同一报价函数，旧报价会在扣费前返回 409。视频默认仍为 720p、5 秒。

失败任务若供应商已报告实际成本，则仅保留覆盖该成本与 5% 手续费预算的积分，退回其余积分，不保留 20% 利润空间。保留积分不会超过原报价；供应商明确成本为 0 时全退，成本缺失时维持原有退款策略。历史成功任务不重新计费。

## 验证

- `npm test`：五接口注册、输入校验、媒体映射、首尾帧、透明图、自定义尺寸边界、六图输出、逐档计价和参考视频费用。
- `npm run verify:seed-models`：通过真实 POST 处理函数验证五条提交路径、扣费金额、参数持久化、身份/配置/报价守卫与失败前不扣费。数据库和供应商传输均为测试替身。
- `npm run check`：项目完整检查和生产构建。

验证不会发送真实付费生成请求。上线后需使用服务器现有部署流程构建并重启 `dreamface`。
