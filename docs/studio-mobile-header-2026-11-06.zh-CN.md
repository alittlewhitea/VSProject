# 移动端顶部与侧边菜单

- 768px 以下顶部仅保留左侧侧栏按钮、静态工作区标题、右侧带文字的购买积分按钮。主题、账号和语言入口移入侧边菜单；工作区切换通过同一菜单完成。桌面布局保留。
- 菜单为可独立滚动的侧边抽屉，保留全部工作区、项目、账单、登录和 16 种语言入口，支持遮罩关闭、Escape、焦点约束及关闭后焦点恢复。适配底部安全区及 RTL。
- 深浅模式按钮显示对应文字，沿用原存储键；同一页面内的按钮同步状态，窗口放大至桌面时不会出现按钮状态不同步。浏览器禁用存储时，当前页面仍可切换并在重新打开菜单后保持主题。
- 购买积分沿用现有弹窗和处理函数；本次未修改生成、计价、支付 API 或数据库。
- 深色抽屉的文字、图标、当前工作区和语言按钮使用现有动态 Tokens，避免旧工具类颜色导致对比度偏低。

验证：类型检查、工作区导航与输入回归、Billing 回归及生产构建；Chrome 覆盖 320px 简体中文、390px 英文/阿拉伯文、430px 葡萄牙文，检查两个顶部操作、主题切换、工作区导航、语言、积分弹窗和桌面切换。截图与报告位于 `outputs/mobile-header-20261106/`。测试未调用付费生成或真实支付。
