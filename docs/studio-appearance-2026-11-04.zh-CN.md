# 工作台视觉改版与深浅主题

> 本文记录第一版改动。当前设计以 `public/DreamFace-DESIGN.md` 及 `docs/studio-design-refactor-2026-11-04.zh-CN.md` 为准：默认浅色外壳与独立深色预览区，并保留深色外观切换。

日期：2026-11-04。当前为本地预览，未提交、推送或部署。

## 设计范围

- 首页：创作输入区、视频／图片／音频入口、现有视频案例、最近作品，以及图片增强、去背景、音乐和数字人快捷入口。
- 导航：统一线性图标、选中状态和间距，保留折叠侧栏、移动菜单、原有语言选择与积分入口。
- 视频：压缩参数区、扩大预览区；移动端参数改为两列。保留模型选择、提示词增强、首尾帧、画质、时长、高级选项、报价及生成回调。
- 图片、音频、数字人：左侧输入与设置，右侧展示已有任务输出。完成、排队和失败状态均来自现有任务数据，未添加模拟作品或额外历史查询。
- 深浅主题：默认深色，顶部太阳／月亮按钮切换；浏览器本地保存选择，刷新后恢复，其他标签页同步。按钮说明覆盖原有 16 种语言。
- 模型弹窗使用相同主题，并适配 RTL 方向；原有焦点恢复和 Esc 关闭逻辑保留。
- 付款弹窗保留原有独立样式与付款流程。

## 边界

没有修改 `src/app/api`、数据库结构、数据库数据、`src/lib` 下的生成／价格／支付规则。

对比 Git 原版本，以下 11 个函数的内容（忽略换行符差异）完全一致：`isProviderAllowedForMode`、`providerForWorkflow`、`applyWorkflow`、`applyProvider`、`handleReferenceFiles`、`handleAvatarAudioFile`、`saveLoginDraft`、`handleGenerate`、`handleGenerateClick`、`openBillingModal`、`startStudioCreditCheckout`。

首页输入通过已有 URL 参数处理流程进入对应工作台；主题切换只修改显示属性与外观偏好。新增结果预览仅消费已有任务列表，不改变任务同步与生成流程。

## 校验

- `npm run check`：类型检查、16 语言字典检查、项目既有安全／支付／模型／历史／导航回归检查及生产构建通过。
- `npm run verify:pricing`：通过。原测试的公共报价参考断言固定为 10 月促销价，原先随当前日期失效；现仅在加载该测试模块时固定到其对应的 2026-10-23，之后立即恢复时钟。价格业务代码没有变化。
- 浏览器回归：1440、1024、768、390、360 像素宽度；视频／图片／音频／数字人模式切换与浏览器前进后退；主题切换保留提示词及报价；主题刷新记忆；模型弹窗与键盘焦点；多语言与 RTL。
- 文生视频、图生视频请求使用浏览器本地拦截，验证模型、时长、画质、安全选项、积分及上传图片参数。没有触发真实付费生成。
- 浏览器记录与实际页面截图：`outputs/studio-redesign-20261104/`。最终生产浏览器结果见 `regression.json`。
