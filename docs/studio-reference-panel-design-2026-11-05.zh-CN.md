# 图生图参考图片上传区

按照 `public/DreamFace-DESIGN.md` 的中性面板、克制紫色操作和渐进披露原则，在现有工作台内重新排版参考图片区域。

从“去制作同款”进入时，显示两个明确分区：左侧“模板参考”，负责构图、配色和光影；右侧“你的主体”，用大号加号与虚线上传框提示用户上传自己的产品或人物。已有主体时显示预览和“添加更多图片”。不把主体上传设为硬性必填，保留原有仅使用模板生成变体的能力。

普通图生图仍提供参考图网格及明显的上传入口，不将任意图片误标为模板。长图片 URL 默认折叠在“添加或编辑图片链接”内，仍支持多行编辑。保留设备多图上传、拖拽、单张移除、清除全部和超过八张的展开入口。上传状态避免重复点击，同一文件可在移除后重新选择。

模板 URL 和上传图片保持原有合并顺序：模板在前，用户图片随后。未改动后端、生成接口、模型、积分、登录和任务交互。增强修复与背景移除仍使用原有输入组件。

## 验证

- 八种桌面、平板和手机尺寸检查卡片对齐、真实文件选择器、键盘上传、44px 删除触点及横向溢出。
- 16 种语言、RTL 与深浅主题检查；小屏减少重复提示，避免长文案挤压上传图标。
- 上传、同文件重选、多图追加、单图删除、拖拽、URL 编辑、清空及原有双图模板入口回归通过。
- 两次本地拦截的生成请求验证完整模板 URL 在前、用户上传在后；无真实生成调用。
- 类型、语言键、Studio 输入和生产构建检查通过。
