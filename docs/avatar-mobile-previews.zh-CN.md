# Avatar 移动端视频预览

窄屏或触摸设备浏览 Avatar 列表时，自动选择可视区域内靠近屏幕中央的最多两个卡片，播放静音、循环、内联的视频预览。人物分组与两列造型列表共用该规则；分组只有封面时，继续使用原有的懒加载接口获取预览视频。

滚动时按当前卡片位置重新选择，离屏、切换工作区或关闭页面时暂停并释放旧播放源。未选中的卡片保留图片，不请求视频。视频缺失或失败时保留封面；失败卡片不占预览名额。尊重系统的减少动态效果偏好，浏览器拒绝自动播放时继续显示图片。

造型卡片可点击暂停或恢复；点击其他可见造型会替换一个播放名额，同时最多两个。继续滚动后恢复按屏幕中央位置选择。人物分组的点击仍进入造型列表，桌面端保留原来的单个鼠标悬停预览。

`npm run verify:avatars` 包含选择规则和 Avatar 原有接口回归。`node scripts/verify-avatar-previews-ui.mjs` 需要本地服务 `127.0.0.1:3000` 和隔离 Chrome CDP `127.0.0.1:9358`，使用模拟目录与本地已有视频验证实际播放、滚动切换、隐藏标签页、减少动态效果、失败回退、点击控制、桌面悬停和卸载清理。结果及截图保存到 `outputs/avatar-mobile-previews/`，不会生成内容或付款。
