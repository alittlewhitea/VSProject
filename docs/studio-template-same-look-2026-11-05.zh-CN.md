# 图片制作同款与双参考图

## 行为

首页混合模板区和图生图模板区的图片预览，右下角按钮统一为“去制作同款”。点击进入 `/studio?mode=image&workflow=image-to-image`，带入模板的完整公开图片 URL，并按推荐方案 1 填写当前语言的默认 Prompt。操作只准备编辑内容，不自动生成。

参考顺序沿用现有生成请求：URL 字段中的模板图在前，本地上传图片随后追加。上传用户图片时保留模板地址；切换图生图模型后保持两张参考图和用户编辑过的提示词。已有图生图中替换模板时保留用户上传图；从视频等其他工作区进入模板时清理旧工作区的输入帧，避免误当成产品图。

默认 Prompt 将第一张图定义为构图、配色、背景、光影和版式参考，后续图片定义为用户主体，保留产品／人物特征及已有标识，匹配透视、比例、阴影和反射，不照搬无关品牌或文案。只有模板图时生成同风格变体。支持 16 种语言，提示词始终可编辑。

视频模板仍保留原来源操作，等待以后接入 video-to-video。

## 关键修复

这批 CDN 地址包含 `width=1080,quality=80,format=auto`，之前按任意逗号分隔会错误拆开一张图片。新增 `parseStudioReferenceImages`，仅按换行或后面跟着完整新 URL 的逗号分隔；保留 CDN 参数逗号、图片查询参数和 data URI 的逗号。

实际输入合并、去除内置示例及 Avatar 默认参考清理使用同一解析器。没有修改后端、模型接口、积分计算或订单逻辑。上传图保存在原有客户端状态，不写入 URL。
